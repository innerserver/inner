Connectifi build v194

Changes in this package:
- Account manager no longer opens every member by default.
- Added a dedicated Collapse list / Expand list control that keeps search and filters visible.
- Searching or filtering automatically expands the matched account results.
- Show all members is now an explicit choice and remembers only after being selected in this version.
- Sidebar organization and all existing routes, permissions, and account controls are preserved.

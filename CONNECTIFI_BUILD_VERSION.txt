Connectifi build v198
Released: 2026-09-03

Changes in this package:
- Added server-enforced hostile-origin rejection for cookie-authenticated writes.
- Added core browser security headers, static HEAD support, and real 404 responses for unknown paths.
- Added login rate limiting and reduced the default persistent-session lifetime to 30 days (configurable by environment).
- Scoped lower-privilege state payloads to remove sensitive settings, location arrays, contact fields, and message source metadata.
- Removed stale localStorage-based client-side admin gating and aligned the PWA start URL/cache version.

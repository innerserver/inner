BACKBLAZE B2 UPLOAD SETUP FOR RENDER

REMOVE THESE OLD/STale STORAGE VARS unless you are intentionally using them:
MONGODB_URI
INNER_MONGODB_URI
CLOUDINARY_CLOUD_NAME
CLOUDINARY_API_KEY
CLOUDINARY_API_SECRET
INNER_CLOUDINARY_CLOUD_NAME
INNER_CLOUDINARY_API_KEY
INNER_CLOUDINARY_API_SECRET

ADD THESE FOR BACKBLAZE:
INNER_UPLOAD_PROVIDER=backblaze
INNER_REQUIRE_CLOUD_STORAGE=true
INNER_B2_KEY_ID=your_backblaze_keyID
INNER_B2_APPLICATION_KEY=your_backblaze_applicationKey
INNER_B2_BUCKET_NAME=your_bucket_name

OPTIONAL if Backblaze shows it:
INNER_B2_BUCKET_ID=your_bucket_id

IMPORTANT:
- keyID goes in INNER_B2_KEY_ID.
- applicationKey goes in INNER_B2_APPLICATION_KEY.
- bucketName is the bucket name, not keyName.
- Do not put keyName into bucketName.

LIVE STATUS:
- HTTP working means the server is running.
- The topbar says Live only when the WebSocket /ws connects.
- If it says Not live on Render, check Render logs for restarts or memory crashes, and make sure you are opening the HTTPS Render URL, not a file path or old localhost URL.

INNER APP

1. Right-click Inner-App.zip and choose Extract All.
2. Open the extracted folder.
3. Double-click Inner.exe.

Do not run Inner.exe from inside the zip preview, and do not move only Inner.exe by itself.
Inner.exe must stay in the same folder as:

- server.js
- node.exe
- public

When Inner starts, it opens the local website:

http://127.0.0.1:3000

Click "Enable alerts" in the top bar if you want message popups while Inner is open.
Click "Install app" in the top bar to install the browser version when your browser supports it.
Use the Store tab for paid item requests. Admins can create paid items in the Admin panel.
The AI helper is in the Admin panel. Admins can paste an OpenAI API key there, or start Inner with OPENAI_API_KEY set.
Messages and DMs can include photo/video attachments.

For another laptop:

1. Keep Inner.exe running on the main laptop.
2. Connect both laptops to the same Wi-Fi.
3. On the other laptop, open the "Other laptops on the same Wi-Fi" link shown inside the Inner window.
4. If Windows asks about firewall access for node.exe or Inner, allow it on Private networks.

Your saved data is stored in the data folder beside Inner.exe.

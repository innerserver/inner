# Connectifi v242

## Class rooms

Saving a different class in Profile moves a member into that class room and removes access to their previous class room. Admin changes to a member's class also update membership. Active sessions receive the new class and room immediately. Login reconciles existing accounts.

Rooms named `9A`, `Class 9A`, or `Grade 9A` are recognized as class rooms. Matching is exact: 9A and 9B are separate class rooms. If no matching room exists, the server creates a restricted class room automatically. Teachers and moderators retain their existing room access.

## Questionnaires

Teachers and moderators create questionnaires from Dashboard and target one room or grade. Whole grades include their sections: grade 9 includes 9A, 9B, and 9C. Room targeting follows room membership; targeting a public room includes its members, which can be everyone.

The builder supports short answers, paragraphs, multiple choice, checkboxes, and required questions. Members see questionnaires on Dashboard, submit once, and review their own response. The sender can view responses by member, option totals, members awaiting a response, download CSV, and close submissions. Built-in administrators can also view results.

Audience access follows the member's current class. Submitted answers remain in the sender's results after a member changes class. Questionnaires and responses use the existing server persistence and are included in new backups.

# Connectifi v244

Cleaned up the forms builder, response screen, and results UI. Dialogs have a wider desktop layout, aligned sticky headers and action bars, responsive mobile fields, and numbered question blocks. The builder separates title/description and audience settings from questions, supports moving and duplicating questions, and includes a preview before sending.

Results now have Summary and Individual tabs. Summary shows actual choice counts and progress bars; Individual shows each respondent's username, class, submission time, and answers. Pending members and CSV downloads remain available. Nested dialogs now handle Escape and focus within the active dialog.

The member dashboard still only displays forms awaiting a response. Account provisioning, admin credentials, and the sidebar were not modified.

Verification: JavaScript syntax and focused form rendering/interaction checks. No live browser debugging, full audit, or Render deployment verification was performed.

# Connectifi v253: room synchronization, chat exports and status cleanup

16 November 2026.

## Approved recommendation 3: disconnected helper files

Removed the unreferenced public/chat-export.js and public/performance-patch.js files. Their old routes and localStorage-based admin UI assumptions were disconnected from the active app. The active authenticated /api/chats/export route remains. No account credential, admin privilege or sidebar layout change is included.

## Approved recommendation 6: one class-room roster policy

Startup, single-account class synchronization and approved promotion now all use lib/grade-rooms.js to assign allowedUsers for shared grade rooms and legacy class/section rooms. Grade 8 includes 8A/B/C, while old Class 8A history remains accessible to its matching section under the existing access policy. The helper refreshes legacy section membership from the current roster at startup as well as login and promotion. It retains old room IDs and messages. Existing queues, session refreshes and promotion approval/recovery remain.

## Approved recommendation 8: connection status

Removed status-guard.js and its page-wide MutationObserver. app.js now owns connection state and rendering. Live, Not live and Signed out reflect the canonical state and respect configured connected/disconnected labels. Settings changes rerender the current state. Existing hidden server/version indicators remain hidden without observer churn.

## Graduation export scope and personal chats

Graduates retain one calendar month to export. The server reloads their own account and checks the existing deadline. Exports contain currently accessible rooms and stored room messages, current group DM metadata, and messages whose stored participant list includes the caller. Group messages also require current membership in the matching group record. Other groups, former memberships, missing groups and nonparticipating messages are excluded. Public school rooms remain accessible to all accounts under the existing room policy.

Personal DMs have no grade filter. Grade promotion changes class membership without clearing personal DMs, group DMs or group membership. Item 7, the batched expired-account cleanup proposal, remains on hold. Existing account expiry and cleanup behavior remains in place and does not delete shared message history.

Exported attachment references are not file bytes. Deleted or expired history cannot be restored by exporting.

## Verification

15 focused grade/export/status regressions and 20 existing school regressions pass. They cover promotion preserving DMs and group membership, export exclusion of other/former groups, section privacy, shared roster convergence, newcomer allocation, deadlines and custom status labels. Syntax and diff checks pass. No full audit or browser debugging was performed.

# Connectifi v254: private and public sticker library

16 November 2026.

## Library controls

Room and DM sticker pickers now offer All available stickers, My stickers and Public library. Search matches names, owners and visibility across the available catalog. The picker renders up to 120 matches at a time with lazy-loaded images; search narrows larger catalogs. Opening a library refreshes its current server-visible entries.

New uploads offer an explicit Private/Public choice and default to Private. The owner can change a saved sticker's visibility or remove it. Public stickers are available to all signed-in accounts without admin approval. Private stickers appear only in the owner's library. Existing compatible image and WhatsApp ZIP import instructions remain. Account changes reset the upload choice to Private and clear stale library content.

## Privacy and sent messages

Sticker imports store backing uploads as private files, even when the owner publishes the sticker. Authenticated sticker image routes enforce current public/owner visibility, or permission to read a conversation where the sticker was sent. Sending a private sticker does not add it to the recipient's library. Recipients can still view sent images after the owner removes the library entry or makes it private. Copies already sent or downloaded cannot be recalled by changing library visibility.

At startup, existing owned sticker image records receive private backing-file flags. Legacy attachment URLs keep working for authorized conversation recipients and public library users, while unrelated ordinary users cannot fetch a private sticker by guessing its file URL. Existing administrator file access remains unchanged. Removing a sticker does not delete its backing image or historical messages.

Only the owner can update visibility or remove an entry. Registration requires owned, supported image records and excludes school-submission files or non-clean scan states. Library writes and backing-file writes use their respective queues so simultaneous operations do not overwrite each other. No third-party sticker service or new subscription is added.

# Connectifi v255: dark contrast and connected-chat logo

17 November 2026.

## Readable dark surfaces

Added a final theme-contrast layer after the existing shared UI styles. Dark uses a dark green/charcoal background with lighter text and green accents. Night, Slate, Glass and custom palettes remain available. The browser's native control colour scheme and mobile browser theme colour follow the active palette.

Filled actions use a dedicated foreground selected against the actual accent colour. Nested bold labels follow that same foreground instead of inheriting unrelated dark-mode text rules. Filled controls change colour without an intermediate transition that could briefly pair a previous background with new text. Menus, placeholders, dropdown options, selection and caret colours use the active palette.

White document pages have a separate light text/background context within the dark workspace, including readable links and placeholders. No inversion filter is applied to images, stickers, uploaded documents or video. Custom colour choices and photo backgrounds remain supported. Custom text colours below a 4.5:1 contrast ratio against the custom surface receive a readable runtime fallback, without rewriting the saved preference.

## New logo

Replaced the old CSS grid glyph with an original SVG of two overlapping chat bubbles, using Connectifi green, off-white and sage. The same mark appears at sign-in, in the existing sidebar brand footprint, as the favicon and in the install manifest. No sidebar layout or navigation structure was changed. The old icon URL serves the same new mark for compatibility.

## Focused verification

Local sample renders cover desktop and mobile messages, a dark dialog and the logo on light/dark backgrounds. Twenty-four sampled foreground/background pairs across Light, Dark, Night, Slate, Glass and a custom palette exceed 4.5:1 contrast. These checks cover sampled controls and white document text/links, not every possible user-authored colour or custom CSS rule. Two helper regressions cover accent selection through all gray values and supported-colour handling. No live account or signed-in browser session was used, and no full audit was run.

Inner Google Helper

This extension opens Google Docs, Slides, and Sheets in real Chrome tabs and lets users share links back into Inner.

Install locally

  1. Download inner-google-helper-chrome-store.zip.
  2. Extract the ZIP to a folder.
  3. Open chrome://extensions.
  4. Turn on Developer mode.
  5. Click Load unpacked.
  6. Select the extracted extension folder.
  7. Pin the extension, open it, paste your Inner app URL, and press Save URL.

Publish to Chrome Web Store

  1. Go to Chrome Web Store Developer Dashboard.
  2. Sign in with your Google developer account.
  3. Create a new item and upload the ZIP.
  4. Use the listing text from extensions/inner-google-helper/CHROME_WEB_STORE_LISTING.md.
  5. Submit for review.
  6. After Google gives you the public or unlisted Chrome Web Store URL, paste it into Admin > Server > Chrome Web Store extension link and save.

Publishing requires your Google account and Chrome Web Store review, so Inner cannot auto-publish it from the app.

Emergency controlsEmergency mode marks the HMD dashboard as emergency-ready. Metrics enabled turns HMD metric panels on. Theme engine sets the HMD/system theme preset.
BotsCreate named bot records for helper/moderation automation planning. Enabled means the bot is active in the HMD registry.
PluginsCreate plugin hook records. Hook is the event name, like message or report, and notes explain what it should do.
Auto moderationTurns on spam limits and muted-word checks. Window seconds is the time window; max messages is how many messages are allowed in that window.
Database, storage, localhostDatabase viewer shows saved record counts, storage manager shows upload/data usage, and localhost tools show LAN/local testing links.

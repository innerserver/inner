Admin Guide

Use this for account review, friend/grade setup, announcements, signup mode, hidden tabs, browser rules, calls, screen share, logs, reports, backups, and scaling.

AccountsFriendsCallsBrowser rulesBackups

Signup Mode

  1. Open Admin > Server.
  2. Choose Request approval or Open signup.
  3. Request mode makes the public button say Request account.
  4. Open signup makes the public button say Create account.

Accounts

  1. Public admin accounts show first.
  2. Search by username, name, email, phone, grade, role, IP, or device.
  3. Use Show all only when needed.
  4. Set or fix grade/class on account rows when users cannot find classmates.
  5. Approve/decline requests from Account requests.

Friends and Grade Search

  1. Members should save Profile with grade, email, and phone first.
  2. Friends > Grade dropdown shows same-grade candidates.
  3. The user selects a candidate and presses Add friend.
  4. The recipient accepts under Friends > Requests.
  5. Outside-grade adds require exact username search.
  6. If a user cannot see classmates, check both users have the same grade saved on their account/profile.

Features and Browser

  • Hide tabs from normal users through feature visibility.
  • Allow specific users when needed.
  • Use Browser rules to block domains or enable allow-only mode.
  • Docs controls Google Docs, Slides, and Sheets together.

Calls and Screen Share

  • Voice/video/screen share require HTTPS or localhost.
  • Calls across different networks usually need TURN relay credentials.
  • Set INNER_TURN_URLS, INNER_TURN_USERNAME, and INNER_TURN_CREDENTIAL in the host environment.
  • Use INNER_RTC_RELAY_ONLY=true only after TURN credentials are confirmed.
  • Some phones cannot share screen from browser; use desktop Chrome/Edge for screen share.

Theme and Phone Logout

  • Profile themes now apply to app text, forms, menus, cards, and DMs.
  • Dark-mode readable themes are Dark, Midnight, Slate, Glass, and Custom.
  • After logout on phone, the login/request forms must stay scrollable.
  • If users see old CSS after deploy, tell them to close/reopen the home-screen app or hard refresh.

Logs and Backups

  • Search logs by user or date.
  • Export logs before wiping.
  • Create backups before major admin changes.
  • Use rollback/reinstate when a saved backup is needed.

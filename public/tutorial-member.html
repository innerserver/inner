Member / Student Guide

Use this when your account role says member. This covers profile, friends, chat, files, Google Workspace, and phone setup.

ProfileFriendsDMsGoogle Workspace

First Login

  1. Read Dashboard announcements.
  2. Press Show guide if you dismissed the in-app guide.
  3. Open Profile and set display name, profile picture, grade, bio, and theme.
  4. On phone, use the three-line menu to open the sidebar.

Friends and DMs

  1. Use Friends to find same-grade people.
  2. To find someone outside your grade, search exact username.
  3. Create DMs and group chats with accepted friends only.
  4. Use Browser share controls to send links to friends or groups.

Files

  • Public uploads are visible in the file list.
  • Private uploads are visible to you and admins.
  • Use clear filenames so people know what they are opening.

Google Workspace

  • Use the one Google Workspace tab for Docs, Slides, and Sheets.
  • Use Docs for documents.
  • Use Slides for presentations.
  • Use Sheets for spreadsheets.
  • If Google blocks sign-in in the frame, open full tab once and return to Inner.

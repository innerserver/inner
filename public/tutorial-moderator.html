Moderator / Teacher Guide

Use this for teacher/moderator accounts. Moderator accounts should be assigned manually by admins, not created by open signup.

RoomsFriendsReportsCallsSafety

Daily Use

  1. Check Dashboard announcements.
  2. Open Profile and confirm display name, grade/staff label, email, and phone.
  3. Use Messages for room conversations.
  4. Use DMs only with accepted friends or work groups.
  5. Use the Google Workspace tab for Docs, Slides, and Sheets class work.

Friends and DMs

  1. Open Friends.
  2. Use the grade dropdown to find people in the same grade/group.
  3. Search exact username for anyone outside your grade/group.
  4. Send the friend request and wait for Accept.
  5. Open Direct messages to DM accepted friends or create group DMs.
  6. Use + for attachments, photos, appearance, secret message, groups, and link/doc sharing.

Moderation

  1. Help keep chats organized and respectful.
  2. Review reports only if admin granted access.
  3. Escalate account, safety, or access problems to admins.
  4. Do not change account roles unless you have explicit admin access.

Calls and Sharing

  • Use Call or Video from a selected DM/group.
  • Screen share requires HTTPS or localhost and a browser with display capture.
  • Use desktop Chrome/Edge for the most reliable screen sharing.
  • Different networks may need TURN relay settings configured by an admin.
  • Share Google Workspace links to friends/groups inside Inner.
  • Use the Browser tab only for allowed sites.
  • Files can be private when needed.

Phone and Theme

  • Install Inner to the home screen.
  • Use the three-line menu for navigation.
  • Keep alerts enabled if you need live updates.
  • Dark, Midnight, Slate, Glass, and Custom themes apply across forms, menus, DMs, and panels.
  • After logging out on phone, the sign-in screen should remain readable and scrollable.

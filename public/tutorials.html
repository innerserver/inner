Inner App Tutorial Manual

Use this manual to onboard students, moderators, admins, and HMD/dev users. Inner also has a Dashboard guide inside the app for each account type.

Accounts DMs Files Google Workspace Admin tools

Account Signup

Press the signup button.

It says Request account in request mode and Create account in open signup mode.

Allow location.

When the browser asks, choose Always allow. Inner uses this for server allocation and admin review.

Fill real info.

Use a real name, email, phone number, grade, username, and password.

Wait or enter.

Open signup creates a member account. Request mode shows a review screen until an admin decides.

Daily Basics

  • Dashboard shows announcements, online users, and the guide.
  • Messages are room chats.
  • Friends are added from same-grade search or exact username search.
  • DMs and group DMs work with accepted friends.
  • Call, Video, and Share screen live in the selected DM/group header.
  • Files can be public or private.
  • Use the three-line menu on phone to open the sidebar, and log out normally when done.

Google Workspace and Browser

AreaWhat it doesImportant note
Google WorkspaceUse one Inner tab to switch between Docs, Slides, and Sheets.If Google blocks sign-in in the frame, open full tab once, then return.
FriendsFind same-grade people from the grade dropdown or search exact username outside the grade.Users must save Profile grade first so grade search has the right account data.

Admin Checklist

  • Set Admin > Server > Signup mode.
  • Add report email recipients.
  • Hide Admin, HMD, Domain, or any feature from users as needed.
  • Use Account search before pressing Show all.
  • Use grade filter for grade-level review.
  • Check user/profile grade if friend search is empty.
  • Add TURN values if calls fail across different networks.
  • Export logs before wiping them.

Privacy and Safety

  • Normal users should not see Admin, HMD, or Domain tabs.
  • Private files are visible to the uploader and admins.
  • Users can only friend same-grade people unless they search exact username.
  • Dark themes should keep text readable across forms, panels, DMs, menus, and tutorials.
  • Phone logout should return to a scrollable sign-in screen.
  • Admin browser rules can block websites for normal users.

Phone Setup

iPhone

  1. Open Inner in Safari.
  2. Tap Share.
  3. Tap Add to Home Screen.
  4. Open Inner from the home-screen icon.
  5. Use the three-line menu to open the sidebar.

Android

  1. Open Inner in Chrome.
  2. Tap Install app or Add to Home screen.
  3. Open Inner from the installed icon.
  4. Use the three-line menu to open the sidebar.

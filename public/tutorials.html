Inner App Tutorial Manual

Use this manual to onboard students, moderators, admins, and HMD/dev users. Inner also has a Dashboard guide inside the app for each account type.

Accounts DMs Files Google Docs Slides Sheets Admin tools

Account Signup

Press Create or request account.

The signup/request form is hidden until this button is pressed.

Allow location.

When the browser asks, choose Always allow. Inner uses this for server allocation and admin review.

Fill real info.

Use a real name, email, phone number, grade, username, and password.

Wait or enter.

Open signup creates a member account. Request mode shows a review screen until an admin decides.

Daily Basics

  • Dashboard shows announcements, online users, and the guide.
  • Messages are room chats.
  • DMs and group DMs work with accepted friends.
  • Files can be public or private.
  • Use the three-line menu on phone to open the sidebar.

Tutorials by Account Type

Use the section below for the exact walkthrough each role should follow after logging in.

Member / Student

  1. Set profile picture, display name, grade, status, bio, and theme in Profile.
  2. Find friends by grade, or exact username/email/phone.
  3. Create DMs and group chats with accepted friends.
  4. Use Google Docs, Slides, and Sheets for main work.
  5. Use Inner Docs only as the experimental built-in editor.
  6. Share browser links or doc links to friends from inside Inner.

Moderator / Teacher

  1. Use Messages and DMs to help keep work organized.
  2. Use reports/mod tools only if an admin gives access.
  3. Teacher/mod accounts should be assigned manually by admins.
  4. Use Docs/Slides/Sheets for class work and shared materials.

Admin

  1. Set signup mode, report emails, announcements, and server labels.
  2. Approve or decline account requests.
  3. Search accounts by name, username, email, phone, grade, IP, device, or role.
  4. Hide tabs, lock features, set paywalls, and allow specific users.
  5. Use Browser rules to block or allow sites for normal users.
  6. Create backups and restore from backups when needed.

HMD / Dev

  1. Watch live health, storage, database, logs, and service metrics.
  2. Use emergency controls carefully.
  3. Check localhost tools for desktop/local runs.
  4. Prepare bots, plugins, AI settings, moderation, and recovery tools.

Admin Checklist

  • Set Admin > Server > Signup mode.
  • Add report email recipients.
  • Hide Admin, HMD, Domain, or any feature from users as needed.
  • Use Account search before pressing Show all.
  • Use grade filter for grade-level review.
  • Export logs before wiping them.

Privacy and Safety

  • Normal users should not see Admin, HMD, or Domain tabs.
  • Private files are visible to the uploader and admins.
  • Users can only friend same-grade people unless they search exact contact details.
  • Admin browser rules can block websites for normal users.

Phone Setup

iPhone

  1. Open Inner in Safari.
  2. Tap Share.
  3. Tap Add to Home Screen.
  4. Open Inner from the home-screen icon.
  5. Use the three-line menu to open the sidebar.

Android

  1. Open Inner in Chrome.
  2. Tap Install app or Add to Home screen.
  3. Open Inner from the installed icon.
  4. Use the three-line menu to open the sidebar.
